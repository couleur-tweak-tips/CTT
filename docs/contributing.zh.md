# 贡献指南 { #contribution-guidelines }
这个网站的定位不是事无巨细地收录评测天下所有软件，而是精心挑选值得推荐的那么几个——不过在一个软件的页面底部加一到多个“荣誉提名”分类也是可以的。

你可以把想法告诉我们：

* <div class="annotate" markdown>发到 [CTT Discord](https://discord.gg/CTT) 的 `#suggestions` 版块，或[私信](./contact.md#couleur)(1)</div>

    1.  如果你要写的东西超出 Discord 的 2000 字上限（Nitro 4000 字），可以做个 [Cryptpad](https://cryptpad.fr/pad/) 页面。

或者自己动手干大部分活：

1. [Fork GitHub 上的 `couleur-tweak-tips/CTT`](https://github.com/couleur-tweak-tips/CTT/fork)

2. 提交你的修复 / 想法并[发起 pull request](https://github.com/couleur-tweak-tips/CTT/pulls)

:   这样做意味着你认同以下内容：

    * <u>一个 PR 只讲一件事</u>：一个 PR 里塞太多事情会让取舍变难——哪些是拒绝修改的、哪些是可以保留的。请保持简洁，忠实于你的 PR 标题。
    * 不要留下指向不存在页面的占位链接，如 ``[this](./placeholder/)``
