# CheatBreaker

在官方停更之后，几位开发者（主要是 Tellinq 和 Shon）以非官方形式继续维护 CheatBreaker。它带一个启动器，可以启动 1.7 或 1.8 版本的 CheatBreaker。

* :material-web: <https://cheatbreaker.net>
* :simple-discord: <https://discord.gg/cheatbreaker-633325309395206156>
* :simple-archlinux:{ .archblue } <https://aur.archlinux.org/packages/cheatbreaker>
    * 务必使用 CleanBuild：发布文件名永远相同，默认不会重新下载
* :octicons-book-16: <https://docs.cheatbreaker.net>

# 特性

* 支持现代版本 Java（写作时为 23），[使用更新的版本有助于内存占用、缩放与性能](https://github.com/Mukul1127/Minecraft-Performance-Flags-Benchmarks)。
* 模组开关快捷键（方便按当前游戏模式快速开关 Chat、Armor HUD、Scoreboard 等）
* 可以把模组标签剥掉只留数字（比如 FPS 和药水效果）
* 禁用第一人称火焰（在 Pack Tweaks 模组里）

你可以在 1.7.10 里用上 1.8 的 FPS 模组的 "minimum FPS" 选项：
![](/assets/images/games/minecraft/cheatbreaker/1.7-minimum-fps.png)

它的 Pack Tweaker 模组能玩出不少花样，比如移除物品悬浮提示方便快速补货，或者让物品栏无视资源包直接透明：
![](/assets/images/games/minecraft/cheatbreaker/packtweaker-transparent-inventory.png)

Pack Tweaker 还能做出强力的暗角（vignette）效果：类型设为 static，不透明度拉满 100%：
![](/assets/images/games/minecraft/cheatbreaker/packtweaker-vignette.webp)
