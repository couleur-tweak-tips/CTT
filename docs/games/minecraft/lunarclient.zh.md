* :material-web: <https://www.lunarclient.com/download>
* :package: `winget install Moonsworth.LunarClient`
* :simple-archlinux:{.archblue} <https://aur.archlinux.org/packages/lunar-client>

进入 RSHIFT > MODS > 设置 > 性能（Performance）。

*   `Hide Foliage`：关（会隐藏草和高草丛）
*   `Hide End Portals`：Always
*   `Show Enchantment Glint`：None
*   `Lazy Chunk Loading`：最低
    *   该选项会限制区块加载速度，可能影响你的游戏体验。如果你想要更快的区块加载，把它调高。
*   `Shadow`：关
*   `Entities`：最低
    *   该选项会限制实体（玩家、生物等）的加载距离，可能影响你的游戏体验。如果希望实体从更远的地方加载，把它调高。
*   `Tile Entities`：最低
*   `Show Ground Arrows`：关
*   `Show Stuck Arrows`：关
*   `Hide Placed Skulls`：开

### Lunar 各模组的性能开销

_*如果一个模组对你没有任何用途，那你为什么还要开着它呢_ — Tellinq_

* 🟢 Freelook——开着也无开销
* 🟢 FPS
* 🟢 CPS
* 🟢 Saturation
* 🟢 Potion effects
* 🟢 Toggle sprint/sneak——*不用 HUD 文字的话记得关掉它*
* 🟢 Pack Display
* 🟢 3D Skins——*出人意料地轻量*
* 🟡 Armor Status
* 🟡 Custom crosshair
* 🟡 ReplayMod
* 🟡 Coordinates
* 🟡 Keystrokes
* 🟡 Custom sky
* 🟠 Chat（不是说这个模组本身，而是指完全开关聊天功能）
* 🟠 Scoreboard
* 🟠 Net graph
* 🟠 Name tags（同上，指完全开关名牌）
* 🔴 Cooldowns
* 🔴 Motion blur——（因为要让它工作就必须关掉 `Fast Render`）
* 🔴 Fancy direction 

*（以上只在 1.7.10 测过，欢迎其他版本补充测试，私聊告诉我）*
