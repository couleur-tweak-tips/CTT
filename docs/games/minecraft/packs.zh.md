## ov3rlay bundle {#ov3rlay-bundle }
一批脑洞大开的 PvP 覆盖包（overlay），输入 `ov3` 即可搜索到它们。

![](/assets/images/games/minecraft/packs/ov3rlay-search.webp){width="688" height="387"}

### [operation black sky](https://cdn.modrinth.com/data/ur6MjJTP/versions/l1nOvEku/ov3rlay%20operation%20black%20sky.zip) {#operation-black-sky }
把天空变成纯黑，OBS 编码起来更轻松。

需要开启的设置：

* Custom Sky（自定义天空）：开
* Sky（天空）：关（如果开着，上半块天空不会变黑）
* Stars（星星）：开
* Sun & Moon（太阳与月亮）：关

![](/assets/images/games/minecraft/packs/operation-black-sky.webp){width="688" height="387"}

### [clean items](https://cdn.modrinth.com/data/ur6MjJTP/versions/ZpBZFC9u/ov3rlay%20clean%20items.zip) {#clean-items }
* 把所有 NoDebuff 相关物品的物品名清空
* 让物品栏 GUI 隐形
* 确保你的游戏语言是 English (US)

![](/assets/images/games/minecraft/packs/clean-items.webp){width="688" height="387"}

### [fireless](https://cdn.modrinth.com/data/ur6MjJTP/versions/xJvLuVBe/ov3rlay%20fireless.zip) {#fireless }
让玩家身上的火焰隐形。

不需要开启 Details（细节）里的 Fire Animated（火焰动画）。

![](/assets/images/games/minecraft/packs/fireless.webp){width="688" height="387"}

### [blocks](https://cdn.modrinth.com/data/ur6MjJTP/versions/gTo4FcQO/ov3rlay%20b%26w%20blocks.zip) {#blocks }
通用方块覆盖包，方块材质来自 Ricardoh。

![](/assets/images/games/minecraft/packs/blocks.webp){width="688" height="387"}

### [b&w blocks](https://cdn.modrinth.com/data/ur6MjJTP/versions/gTo4FcQO/ov3rlay%20b%26w%20blocks.zip) {#bw-blocks }
同上，但去掉了饱和度。
