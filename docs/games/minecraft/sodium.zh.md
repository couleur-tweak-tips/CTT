# Sodium

Sodium 是现代版本 Minecraft 中 [OptiFine](optifine.md) 的替代品，需要通过 [Fabric 模组加载器](https://fabricmc.net/)（[Forge](https://files.minecraftforge.net/) 的替代品）使用。

有些资源包用到了 Sodium 没有的 OptiFine 专属特性，[这份清单里的模组实现了其中一部分](https://microcontrollersdev.github.io/Alternatives/latest/migrating/#resource-packs)。


### 获取 Sodium

* :simple-github: <https://github.com/CaffeineMC/sodium>
    * :simple-modrinth:{.mr} <https://modrinth.com/mod/sodium>

我还推荐以下模组：

* :simple-github: <https://github.com/FlashyReese/sodium-extra-fabric>
    * :simple-modrinth:{.mr} <https://modrinth.com/mod/sodium-extra>
* :simple-github: <https://github.com/FlashyReese/reeses-sodium-options>
    * :simple-modrinth:{.mr} <https://modrinth.com/mod/reeses-sodium-options>


# 配置

关掉 V-Sync（垂直同步），关掉进度提示（advancement toasts）。如果你还知道别的可折腾项，[告诉我](/contact)。
