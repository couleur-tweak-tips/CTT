#### 禁用 Firefox 全屏淡入淡出

在 `about:config` 里：

```
full-screen-api.transition-duration.enter
full-screen-api.transition-duration.leave
```

把这两项都设为 `0 0`。

yf 复制链接到剪贴板

[Chrome 应用商店](https://chromewebstore.google.com/detail/vimium/dbepggeogbaibhgnhhndojpepiihcmeb)
