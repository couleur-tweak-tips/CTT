## 怪癖说明： {#quirks-explained }
`无内嵌`

: 网站不提供热链 / 直链——把链接发到 Telegram / Discord 里不会附带视频播放器

`视频播放器`

: 网站自带视频播放器，不用下载整个文件就能看（比如电影）

`个人运营`

: 不属于公司——多半是某位好心人在免费托管。

`Pomf`

:   站点基于 [Pomf](https://github.com/pomf/pomf) 托管引擎
