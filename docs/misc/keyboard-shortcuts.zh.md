### :material-minecraft: **Minecraft** {#minecraft }
* 开着聊天框时按上方向键，可以翻看你发过的历史消息。
* 在服务器列表里按 F5 刷新——测 ping 很方便。
* `TAB` 自动补全命令/玩家名。


### :simple-discord: **Discord** {#discord }
* ⭐ `CTRL+SHIFT+ALT+V` 聚焦到你当前所在的语音通话
* ⭐`CTRL+SHIFT+A` 收起全部分类，**__在 CTT 里极其好用__**
* ⭐`CTRL+SHIFT+I` 打开收件箱，汇总所有服务器/频道/私信的未读与提及
* Discord 里的 `CTRL+K` 非常好用：直接搜你想去的任何地方，回车直达——快多了
* 崩溃了/折腾坏了/想更新？`CTRL+R` 完全重启 Discord
* 输入/编辑消息时 `SHIFT+ENTER` 换行
* 图片上`中键点击`会在浏览器里`打开原图`
* `CTRL+/` 列出 Discord 的全部快捷键
* 快速编辑上一条已发送消息：按 TAB 选到它，再按 E 编辑；按 R 则是回复
* 输入 `+:thumbsup:` 给最新消息加 :emoji: 表情回应
* 杂项：点顶部的帖子标题可以展开整个话题/帖

### :fontawesome-brands-chrome: **浏览器** {#web-browsers }
* `CTRL+W` 关闭当前浏览器标签页（比点那个小 `x` 快一千倍），`CTRL+T` 新开标签页。
* `CTRL+SHIFT+T` 恢复刚关掉的标签页
* `CTRL+TAB`，类似 Windows 的 `ALT+TAB`，以同样方式循环切换 Chrome 标签页
* <https://shortlib.netlify.app/apps/google-chrome> - 快捷键大全

### :fontawesome-brands-windows: Windows {#windows }
* ⭐`CTRL+L` 聚焦资源管理器的地址栏
* ⭐`F2` 重命名选中文件，比右键 -> 重命名快得多
* ⭐`ALT+双击左键` 直接打开文件属性，**实用到哭**
* ⭐`WIN+SHIFT+<方向键>` 把当前窗口挪到左/右侧显示器
* ⭐ `CTRL+SHIFT+ENTER` 在开始菜单搜索中以管理员身份启动第一个结果
* `WIN+.` 打开系统级 emoji 面板
* `WIN+<方向键>` 最大化/最小化/平铺当前窗口（也可以把窗口甩到另一台显示器）
* `ALT+TAB` 在应用间切换，怎么推荐都不为过。
* `SHIFT+DEL` 不走回收站直接删除所选文件
* `WIN+I` 直接打开设置
* `CTRL+SHIFT+ESC` 打开任务管理器
* `WIN+L` 锁定/注销
* `CTRL+SHIFT+N` 新建文件夹
* `WIN+E` 打开 Windows 资源管理器
* `WIN+SHIFT+S` 快速截图，图存进剪贴板，来 <#818422588585672704> 粘贴试试
* `WIN+M` 最小化所有应用（即“显示桌面”）
* <https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec>
    * `"` 打开 USERPROFILE
    * `control` 打开旧版控制面板
    * `cmd` 打开命令提示符 <:cmd:833675462282706964>  
    * `powershell` 打开 PowerShell <:pwsh:907248858973753344> 
    * `appwiz.cpl` 打开旧版控制面板的程序管理器
    * `main.cpl` 打开旧版鼠标面板

### :custom-vegas-pro-18: Vegas Pro {#vegas-pro }
* ⭐`ALT+SHIFT+4`——在另一台显示器全屏预览
* ⭐`Crtl+F4` 关闭项目（*不退出 VEGAS*）
* ⭐`CTRL+LEFT/RIGHT`——在标记点之间移动
* ⭐`ALT+ENTER`——查看项目属性
* `ALT+LEFT/ALT+RIGHT`——逐帧前后移动
* `S`——切开素材
* `Del`——从时间轴删除素材
* `CTRL+C & CTRL+V`——复制粘贴素材
* `CTRL+Shift+Q`——插入新视频轨
* `CTRL+Q`——插入新音频轨
* `CTRL+Z`——撤销
* `CTRL+SHIFT+Z`——重做
* `空格`——播放
* `Crtl+N` 新建项目
* `Ctrl + Shift + N` 新建项目（跳过属性设置）
* `Crtl+O` 打开项目
* `Crtl+S` 保存项目
* `SHIFT+滚轮` 横向滚动

### :material-microsoft-visual-studio-code: VSCode {#vscode }
* `CTRL+L` 选中当前行
* `CTRL+D` 选中词
* `CTRL+X` 剪切当前行
* 对函数 `CTRL+左键` 直达它的声明处
* `CTRL+K CTRL+T` 打开主题选择器
* `ALT+UP/DOWN` 当前行上移/下移
* 按住中键拖动可做矩形文本选区，和 Windows 桌面框选一个道理
