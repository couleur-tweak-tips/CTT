## 应用 {#apps }
# 实用应用，很多都托管在 [F-Droid](https://f-droid.org) {#useful-apps-a-lot-of-them-are-hosted-on-f-droid }
* [Firefox](https://www.mozilla.org/en-US/firefox/browsers/mobile/android/)：支持大量[浏览器扩展](../misc/browser-extensions.md)
* [F-droidify](https://f-droid.org/packages/com.looker.droidify/)：更好用的 f-droid 前端
* [Aurora Store](https://f-droid.org/packages/com.aurora.store/)：更好用的 Google Play 商店前端
* [Aves Libre](https://f-droid.org/packages/deckers.thibault.aves.libre/)：好用到犯规的相册，标签搜索/过滤非常强
* [Revanced](https://revanced.app/)：打过补丁的 YouTube 应用（去广告、SponsorBlock、DeArrow、隐藏 Shorts、海量自定义）。谨防假冒网站——认准 `revanced.app`
    * [Tubular](https://f-droid.org/packages/org.polymorphicshade.tubular/)：一个 [NewPipe](https://f-droid.org/packages/org.schabi.newpipe/) 分支，还能当 SoundCloud 前端用，同样无广告、带 SponsorBlock
* [syncthing-fork](https://f-droid.org/packages/com.github.catfriend1.syncthingandroid/)：同步 Obsidian 笔记很好用！
* [Obtainium](https://obtainium.imranr.dev/)：直接从 GitHub Releases 等来源安装、更新应用
* [Musicolet](https://krosbits.in/musicolet/)：离线音乐播放器，可定制
* [Fossify](https://www.fossify.org/apps/)：一套简洁小应用
* [OpenPods](https://f-droid.org/packages/com.dosse.airpods/)：一眼看清 AirPods 电量
* [p!n](https://f-droid.org/packages/de.nproth.pin/)：把待办和提醒钉成通知，可设过期时间
* [Thunderbird](https://f-droid.org/packages/net.thunderbird.android)：前身 K-9 的邮件客户端
* [Organic Maps](https://f-droid.org/en/packages/app.organicmaps/)：能做谷歌地图式路线规划的 [OpenStreetMap](https://f-droid.org/en/packages/app.organicmaps/) 前端
* [Parsec](https://parsec.app/downloads)：可接键盘——把手机接到显示器上、远程连回你的 PC，就是终极便携形态 :D
