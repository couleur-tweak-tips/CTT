# mpv {#mpv }
可扩展、键盘驱动的媒体播放器。

## 安装 {#installation }
* <https://github.com/mpv-player/mpv#mpv>
* <https://mpv.io/manual/stable> 价值极高

Linux 是一等公民；Windows 上目前还没有官方合入的文件关联器或[装到 PATH 的安装器](https://github.com/mpv-player/mpv/pull/15912)，配置可参考[这篇教程](https://kenhv.com/blog/setting-up-mpv)。

# 配置 {#configuration }
见 [The Wiki 的](https://thewiki.moe/tutorials/mpv/#config-overview) 文档。

# Lua 脚本 {#lua-scripts }
* <https://github.com/couleur-tweak-tips/suckless-cut> 我自己写的 lossless-cut 替代品
* <https://github.com/tomasklaen/uosc> 惊艳的 UI 大改
* <https://github.com/po5/thumbfast> 拖动进度时出现极其精确（或干脆逐帧）的缩略图
* <https://github.com/mpv-player/mpv/wiki/User-Scripts> 官方脚本索引
