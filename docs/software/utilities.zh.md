## 磁盘占用可视化 {#disk-mapping-programs }
让你直观地俯瞰整张磁盘或某个文件夹：每个文件在图上占多大一块，取决于它的实际大小。

部分工具还支持包含/排除规则（比如看看 Prism Launcher 的每个实例里 mod jar 一共占多少 :）

* [WizTree](https://www.diskanalyzer.com/) —— 综合最佳
* [SpaceSniffer](http://www.uderzo.it/main_products/space_sniffer/index.html) —— 有细节程度滑杆，文件被修改时会短暂高亮（网站不支持 HTTPS ⚠）
* [WinDirStat](https://windirstat.net) —— 最出名，扫描最慢

## 差异对比工具 {#diff-programs }
手上有一个东西的两个版本，想把各自的优点合并到一起？

* [BeyondCompare](https://www.scootersoftware.com/)
* [WinMerge](https://winmerge.org/)

## 压缩/解压缩工具 {#compressionarchival-programs }
下载东西时遇到过 .7z 或 .rar 吗？

* [7-Zip](https://www.7-zip.org/) —— 几乎什么都能解，还快
    * [NanaZip](https://github.com/M2Team/NanaZip) —— 7-Zip 的界面重做版，有深色模式

## Directory Opus {#directory-opus }
面向重度用户的文件管理器。

* 付费：90 澳元（约合 55 美元 / 50 欧元），30 天试用（注册后可 60 天）
* :material-web: [gptsoft.com.au](https://www.gpsoft.com.au/)

值得一提的特性：

* 不像资源管理器，可以粘贴带引号和正斜杠的路径

* 响应迅速

* 完整的脚本接口，连对话框都可脚本化
