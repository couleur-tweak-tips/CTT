# Microsoft Visual Studio 家族 IDE {#microsoft-visual-studio-ides }
共有三种 IDE：

* :material-microsoft-visual-studio-code: [Visual Studio Code](https://code.visualstudio.com/Download)：
    * 部分开源
    * 最流行的 IDE
* :simple-vscodium: [VS Codium](https://vscodium.com)：
    * 去掉了遥测的 VSCode 编译版
    * 支持扩展，但用的是[另一个商店](https://open-vsx.org/)

* :material-microsoft-visual-studio: Visual Studio：专攻 C/C++/C# 编程与调试
    * [社区版免费](https://visualstudio.microsoft.com/vs/community/)
    * [旧版本在此](https://learn.microsoft.com/en-us/visualstudio/releases/2019/release-notes)
