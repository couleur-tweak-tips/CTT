# :obs-audio: 音频（Audio） {#audio }
## 配置多音轨 {#configuring-multiple-audio-tracks }
可采集的声音有三种：

* 麦克风 / 摄像头：你自己说话的声音
* 桌面音频：所有应用音频的混合
* 应用音频采集 [BETA]（Application audio capture）：可以按程序分开采集，之后配合多音轨，在剪辑软件里分别调整每个程序的音量。
