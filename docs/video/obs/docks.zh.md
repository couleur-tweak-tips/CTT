# :material-dock-window: 停靠窗格（Docks） {#docks }
OBS 的界面可以通过停靠窗格进行深度定制：

* 蓝色：本文反复提到的 <kbd>View</kbd>（视图）和 <kbd>Docks</kbd>（停靠窗格）按钮
* 绿色：可在 <kbd>View</kbd>（视图）中显隐
* 红色：可在 <kbd>Docks</kbd>（停靠窗格）中显隐

![](../../assets/images/video/obs/docks/docks.png)

## :material-chart-bar-stacked: 统计（Stats） {#stats }
显示录制/串流的状态统计，最常用的是（见上图）：

* 内存占用
* 录制与串流的总输出数据量
* 因编码/渲染滞后而跳过的帧数
* 磁盘剩余空间 / 预计多久录满磁盘

!!! important "查看统计窗格有两种方式"

    1. 在 <kbd>Docks</kbd>（停靠窗格）中启用：把它停靠进界面（如前面所示）
    2. 在 <kbd>View</kbd>（视图）中启用：保持为独立悬浮窗



## :material-projector-screen-outline: 场景（Scenes） {#scenes }
场景是用户自定义来源的集合。典型用户是主播：在游戏画面+摄像头、全屏摄像头和“马上开播”/“马上回来”文字之间切换。

如果你同一时间只用一个来源（比如录游戏），可以删掉场景选择器和场景过渡窗格，给界面腾出空间。

## 管理停靠窗格 {#managing-docks }
直接选 <kbd>Docks</kbd> 或 <kbd>View</kbd> -> 勾选/取消你要的那些即可。
