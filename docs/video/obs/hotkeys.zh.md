!!! info "本页所有按键都是推荐值，<u>OBS 默认没有任何快捷键</u>"

如果给“开始 X”和“停止 X”（或“启用 X”和“禁用 X”）绑同一个键，它就会像开关一样切换。


* `Enable Preview`（启用预览） & `Disable Preview`（禁用预览）：<kbd>CTRL+ENTER</kbd>

:   有助于性能，我喜欢开始录制后禁用预览。

* `Reset Stats`（重置统计）：<kbd>CTRL+SHIFT</kbd>

:   切窗口（alt-tab）总会掉几帧。我喜欢重置一下——这样看它是否超过 0 就行，而不用费力记住之前是多少。


## 回放缓存（Replay Buffer） {#replay-buffer }
* `Save Replay`（保存回放）：默认无

:   想用[回放缓存](./output.md)存片段、又不想切出游戏去点 <kbd>Stop Replay Buffer</kbd> 旁边的小 :material-download: 按钮的话，给它绑个键。
